---
title: "Limites de requêtes"
description: "Chaque réponse indique votre quota — même celles qui refusent votre requête"
---

Chaque clé API peut faire environ **100 requêtes par minute**. Le quota est compté par chacun des serveurs qui répondent à l'API : le nombre exact de requêtes acceptées sur une minute donnée peut donc varier légèrement. Considérez 100 par minute comme un budget à ne pas dépasser, et traitez toujours un `429`.

Chaque réponse — y compris `401` et `403` — porte ces en-têtes (seule une réponse `503 service_unavailable` peut arriver sans eux) :

| En-tête | Signification |
|---|---|
| `X-RateLimit-Limit` | Requêtes autorisées par fenêtre, pour cette clé |
| `X-RateLimit-Remaining` | Requêtes restantes dans la fenêtre en cours |
| `X-RateLimit-Reset` | Secondes avant la remise à zéro de la fenêtre — **pas** un horodatage |

## Quand vous dépassez la limite

Une réponse `429` ajoute un en-tête `Retry-After` (le nombre de secondes à attendre) et le corps d'erreur habituel :

```json
{
  "error": {
    "code": "rate_limited",
    "message": "Rate limit exceeded — retry in a few seconds",
    "details": {
      "retry_after_seconds": 42
    }
  }
}
```

## Ralentir

```bash
response=$(curl -s -w "\n%{http_code}" "https://api.agentova.ai/v1/automations?limit=1" \
  -H "Authorization: Bearer agk_live_your_key_here")
http_status=$(printf '%s' "$response" | tail -n 1)
body=$(printf '%s' "$response" | sed '$d')

if [ "$http_status" = "429" ]; then
  retry_after=$(printf '%s' "$body" | jq -r '.error.details.retry_after_seconds')
  sleep "$retry_after"
  # ...puis renvoyer la requête
fi
```

Lire `X-RateLimit-Remaining` sur chaque réponse et ralentir avant d'atteindre `0` est plus élégant que d'attendre un `429` — et chaque réponse vous donne ce nombre gratuitement.

## Échecs d'authentification

Au-delà de **30 échecs d'authentification en une minute depuis la même adresse IP**, les requêtes suivantes de cette adresse avec une clé absente ou invalide reçoivent `429` au lieu de `401`. Une requête avec une clé valide n'est jamais refusée par cette limite : les outils qui partagent leurs adresses sortantes, comme Zapier, ne sont donc pas pénalisés par les erreurs des autres.
