---
title: "Install the node"
description: "Add the Agentova community node to your n8n instance"
---

The node is published on npm as **`n8n-nodes-agentova-ai`**, built and signed by Agentova's CI (npm provenance).

## Self-hosted n8n

<Steps>
  <Step title="Open Settings → Community Nodes">
    You need to be the owner or an admin of the n8n instance.
  </Step>
  <Step title="Click Install and enter the package name">
    `n8n-nodes-agentova-ai`
  </Step>
  <Step title="Accept the community node warning and install">
    The **Agentova** and **Agentova Trigger** nodes then appear when you search “Agentova” in the nodes panel.
  </Step>
</Steps>

If your instance doesn't allow installs from the interface, install the package with npm in your n8n custom folder (usually `~/.n8n/nodes`) and restart n8n:

```bash
cd ~/.n8n/nodes
npm install n8n-nodes-agentova-ai
```

## n8n Cloud

n8n Cloud only offers community nodes that n8n has verified. The Agentova node isn't verified yet: until it is, use a self-hosted instance.

## Updating

Settings → Community Nodes → the Agentova package → **Update**. Your workflows and credentials are kept.

## Requirements for the trigger

The **Agentova Trigger** receives notifications from Agentova. Your n8n instance must therefore be reachable from the internet, over **HTTPS**, at the address set in n8n's `WEBHOOK_URL`. Agentova refuses to send notifications to plain `http://` addresses, to private or local addresses, and to addresses containing a username or password.
