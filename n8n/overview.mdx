The Agentova node for n8n brings your workspace into your workflows: list and control your automations, and start a workflow the moment a lead comes in, a run finishes or an automation changes status.

## What's in the package

| Node | Kind | What it does |
|---|---|---|
| **Agentova** | Action | Automations: **List**, **Get**, **Activate**, **Pause** |
| **Agentova Trigger** | Trigger | Starts a workflow on **Lead Created**, **Run Completed** and/or **Automation Status Changed** |

Both nodes use the same **Agentova API** credential.

## Before you start

- An Agentova workspace where you're an **admin** (to create the API key).
- An n8n instance where you can install community nodes. For the trigger, it must be reachable from the internet over HTTPS, so that Agentova can notify it.
