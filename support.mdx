Write to **[contact@agentova.ai](mailto:contact@agentova.ai)** for any question about the public API, the Zapier app or the n8n node — or about a mistake in this documentation.

Before writing, [Troubleshooting](/troubleshooting) and the help pages of the [Zapier](/zapier/troubleshooting) and [n8n](/n8n/troubleshooting) tabs answer the most common questions.

## What to include

To get a useful answer quickly, include:

- what you were trying to do, and what happened instead;
- the date and time of the problem, with your time zone;
- for a call: the method and the endpoint, the HTTP status and the error `code` you received;
- the IDs involved: automation (`aut_…`), webhook subscription (`whk_…`), event (`evt_…`), run (`run_…`) or lead (`lea_…`);
- for Zapier or n8n: the name of the step or node, and the message it showed.

<Warning>
  Never send an API key (`agk_live_…`) or a webhook secret (`whsec_…`), not even partially. If you shared one by mistake, revoke the key in **Paramètres → API** or replace the subscription.
</Warning>

## Security issues

To report a vulnerability, write to the same address — see [Security](/security#reporting-a-vulnerability).
