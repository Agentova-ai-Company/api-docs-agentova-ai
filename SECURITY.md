# Security policy

This repository contains documentation only. It holds no credentials: the API
keys and webhook secrets described in the pages are examples, never real values.

## Reporting a vulnerability

If a page documents something that would weaken the security of an integration
(a wrong signature check, a misleading authentication example), or if a secret
was committed by mistake, please **do not** open a public issue.

Use GitHub's private vulnerability reporting on this repository
(*Security* tab → *Report a vulnerability*). You will get an acknowledgement and
the page will be corrected on the deployed site.

Vulnerabilities in the API itself follow the Agentova security policy published
on the portal.
