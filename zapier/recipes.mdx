Each recipe lists the steps to create in the Zap editor. Replace the example names with yours.

## Pause an automation at night, reactivate it in the morning

Useful when your team wants to answer messages itself outside office hours — or the opposite.

<Steps>
  <Step title="Zap 1 — Trigger: Schedule by Zapier">
    **Every Day**, at 7:00 pm.
  </Step>
  <Step title="Action: Agentova — Find Automation">
    **Name**: a word from your automation's name, for example “Instagram”.
  </Step>
  <Step title="Action: Agentova — Activate or Pause Automation">
    **Automation**: the ID found in the previous step. **Status**: `Paused`.
  </Step>
  <Step title="Zap 2 — same thing at 8:00 am">
    Duplicate Zap 1, change the time to 8:00 am and the status to `Active`.
  </Step>
</Steps>

Running the morning Zap on an automation that's already active is harmless: nothing changes and no error is raised.

## Get alerted when an automation stops working

<Steps>
  <Step title="Trigger: Agentova — Automation Status Changed" />
  <Step title="Filter by Zapier">
    Only continue if **Status** exactly matches `error`.
  </Step>
  <Step title="Action: Slack — Send Channel Message (or Gmail, SMS…)">
    Message: “The automation *Name* (*Agent name*) is in error — check its connection in Agentova.” — insert the **Name** and **Agent name** fields from the trigger.
  </Step>
</Steps>

## Get alerted when a reply fails

<Steps>
  <Step title="Trigger: Agentova — Run Completed" />
  <Step title="Filter by Zapier">
    Only continue if **Status** is `failed` (or `failed` **or** `partial` to also catch half-failures).
  </Step>
  <Step title="Action: your alert channel">
    Include the automation ID, the trigger type and the time, so the team can find the conversation.
  </Step>
</Steps>

## Send every new lead to a spreadsheet or your CRM

<Steps>
  <Step title="Trigger: Agentova — New Lead" />
  <Step title="(Optional) Filter by Zapier">
    Keep only one source, for example **Source** exactly matches `lead_ads`, or one agent with **Agent ID**.
  </Step>
  <Step title="Action: Google Sheets — Create Spreadsheet Row (or HubSpot, Pipedrive…)">
    Map Name, Email, Phone, Source and Created at to your columns.
  </Step>
</Steps>

## Log everything your agents do

<Steps>
  <Step title="Trigger: Agentova — Run Completed" />
  <Step title="Action: Google Sheets — Create Spreadsheet Row">
    One row per run: Occurred at, Automation ID, Trigger type, Status. Handy for a weekly count of what your agents handled.
  </Step>
</Steps>
