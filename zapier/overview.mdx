## Ce que contient l'application

| Dans Zapier | Type | Ce que ça fait |
|---|---|---|
| **New Lead** | Déclencheur | Un nouveau lead a été capté par votre chatbot, un formulaire Lead Ads, votre agent téléphonique, une automatisation de commentaires ou une source CRM |
| **Run Completed** | Déclencheur | L'une de vos automatisations vient de faire quelque chose (répondre, traiter un formulaire…) |
| **Automation Status Changed** | Déclencheur | Une automatisation a été mise en pause, réactivée, arrêtée par une erreur, ou est revenue après la reconnexion de son compte |
| **Activate Automation** | Action | Réactive une automatisation en pause |
| **Pause Automation** | Action | Met en pause une automatisation active |
| **Find Automation** | Recherche | Retrouve une automatisation par son nom ou son ID, pour l'utiliser dans une étape suivante |

Les trois déclencheurs sont **instantanés** : Agentova prévient Zapier dès que l'événement se produit, vous n'attendez pas que Zapier vienne vérifier.

## Disponibilité

<Note>
  L'application Agentova est pour l'instant **sur invitation**, le temps de la validation par Zapier. Dans l'éditeur de Zap, elle apparaît sous le nom « Agentova (1.0.x) — Invite Only ». Demandez un lien d'invitation à Agentova à [contact@agentova.ai](mailto:contact@agentova.ai) ; une fois l'application publique, il suffira de chercher « Agentova ».
</Note>

## Avant de commencer

- Un espace de travail Agentova dont vous êtes **administrateur** (pour créer la clé API).
- Un compte Zapier.
- Au moins une automatisation dans votre espace de travail si vous voulez essayer les déclencheurs et les actions sur les automatisations.
