The Agentova public API (v1) gives you access to your workspace's automations, leads and runs, and lets you pause or reactivate automations. It also notifies you in real time, through webhooks, when a lead comes in, a run finishes, or an automation's status changes.

```
https://core-api.agentova.ai/v1
```

The API is meant to be called **from a server**: it authenticates with a secret key, and it doesn't answer calls made from a web browser (no CORS).

<Note>
  Not a developer? The **Zapier** and **n8n** tabs are step-by-step guides for using Agentova in those tools, without writing code.
</Note>

## Endpoints

<CardGroup cols={2}>
  <Card title="List automations" icon="robot" href="/api-reference/list-automations">
    `GET /automations` — every automation of the workspace, filtered by status, type or agent.
  </Card>
  <Card title="Retrieve an automation" icon="magnifying-glass" href="/api-reference/retrieve-an-automation">
    `GET /automations/{id}` — one automation and its current status.
  </Card>
  <Card title="Update an automation's status" icon="toggle-on" href="/api-reference/update-an-automations-status">
    `PATCH /automations/{id}` — pause or reactivate an automation.
  </Card>
  <Card title="List runs" icon="bolt" href="/api-reference/list-runs">
    `GET /runs` — what your automations did, across the whole workspace.
  </Card>
  <Card title="List leads" icon="address-book" href="/api-reference/list-leads">
    `GET /leads` — the leads captured by your workspace, in one unified shape.
  </Card>
  <Card title="List webhook subscriptions" icon="list" href="/api-reference/list-webhook-subscriptions">
    `GET /webhooks` — the subscriptions of the workspace, active and disabled.
  </Card>
  <Card title="Create a webhook subscription" icon="tower-broadcast" href="/api-reference/create-a-webhook-subscription">
    `POST /webhooks` — receive `lead.created`, `run.completed` or `automation.status_changed`.
  </Card>
  <Card title="Delete a webhook subscription" icon="trash" href="/api-reference/delete-a-webhook-subscription">
    `DELETE /webhooks/{id}` — stop receiving events at that address.
  </Card>
</CardGroup>

The **API Reference** tab also documents `GET /automations/{id}/runs`, the runs of a single automation.

<Note>
  v1 doesn't create or delete automations, and has no manual trigger. It's a stable, deliberately small contract: what you rely on today keeps working — see [Versioning](/versioning).
</Note>

## How this documentation is built

The **API Reference** tab isn't written by hand: it's generated from Agentova's OpenAPI contract, which you can download at `https://docs.agentova.ai/openapi/openapi-v1.yaml`. If a field, an error code or an endpoint looks wrong here, the contract is the source of truth to check first.

Every page is also available as Markdown: use the menu at the top of a page to copy it or open it in an AI assistant. The list of all pages, for AI tools, is at `https://docs.agentova.ai/llms.txt`.
